# 松山湖产业招商网站

面向松山湖及周边企业的写字楼、厂房与产业空间信息网站，支持电脑和手机访问。

**[打开网站](https://ning73988-jpg.github.io/songshanhu-enterprise-spaces/experience/)** · **[管理后台](https://ning73988-jpg.github.io/songshanhu-enterprise-spaces/admin/)**

## 功能介绍

| 功能 | 说明 |
| --- | --- |
| AI 找房 | 已接入 DeepSeek，可描述面积、预算、用途等需求，并继续追问；仅根据本站已发布房源推荐。 |
| 房源筛选 | 支持类型、园区、面积、租金等条件；保留租金、面积和上架时间排序。 |
| 地图找房 | 使用高德互动地图，可拖动、缩放，点击房源价格标记进入详情；页面只保留地图。 |
| 房源详情 | 展示照片、已上传视频、基本参数、费用及招商联系方式，支持分享链接和生成海报。 |
| 留言咨询 | 咨询、看房预约、企业资料及选址需求可提交到后台；原浏览器可查看回复、撤回自己的咨询。 |
| 管理后台 | 房源、留言、数据、地图标注、园区、设置六个板块；支持新增账号、授权已有账号、分配单个或全部园区、停用及移除管理权限。自有大底图入口暂留空。 |

手机端提供玻璃底部导航、滑动切换、房源中心聚焦、相册缩放和保存反馈等交互。

## 使用说明

### 找房与咨询

1. 在首页输入需求，例如“厂房3000平以上，单价不超过15元”，也可以打开筛选面板。
2. 查看推荐房源，或进入“地图找房”点击价格标记。没有填写坐标的房源暂不显示在地图上。
3. 在详情页查看照片和资料，拨打招商电话，或填写联系资料后提交留言、预约。
4. 在“留言咨询”查看本机咨询及后台回复；内容需要更正时，可撤回后重新提交。

> 右上角“登录”目前是预留入口，尚未提供正式访客登录。联系资料和查询回执保存在当前浏览器，换设备不会自动同步；已送达后台的咨询仍保存在云端。

### 管理房源

使用已授权的管理员邮箱和密码登录后台，新增或编辑房源、上传实拍照片与视频，保存草稿或发布；在留言板块处理客户咨询。

超级管理员可在「设置 → 新增管理员 / 编辑」中，将管理范围设为单个园区或「全部园区（房源与留言）」。全园区管理员可管理所有园区的房源与留言，账号权限和平台设置仍由超级管理员维护。已有账号更改范围后，重新登录生效。

内部编号、底价与跟进备注不公开展示。

## 技术与维护

- 前台使用 Next.js 静态构建与原生网页交互，由 GitHub Pages 发布；Supabase 提供数据库、文件存储及服务端函数。
- DeepSeek 密钥与高德安全密钥仅保存在 Supabase 服务端，不写入网页或 GitHub。AI 已设置调用次数限制，推荐结果仍需向招商顾问核实。
- 当前发布流程使用 `site-source-v3.tar.gz` 基础源码包和 `site-update.tar.gz.b64` 更新包，由 GitHub Actions 自动构建发布；后续维护需同步实际源码及更新包。

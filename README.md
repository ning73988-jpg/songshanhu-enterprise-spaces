# 登来产业招商网

为企业找空间，为合作搭桥。汇集松山湖及东莞周边的在租房源与产业资源，支持电脑和手机访问。

**[打开网站](https://denglai.xin/experience/)**

## 功能介绍

| 功能 | 可以做什么 |
| --- | --- |
| AI 找房 | 用日常语言描述面积、预算、格局和用途，继续补充条件，从本站已发布房源中查找合适空间。 |
| 房源筛选与排序 | 按业态、片区、面积、租金、朝向、装修及格局筛选，支持租金、面积和上架时间排序。全部房源每页展示 20 套。 |
| 房源详情与费用 | 查看实拍照片、已上传视频、空间参数、配套说明及公开招商联系方式；分别展示月租金、月物业费和每月合计。 |
| 房源分享 | 复制房源链接或生成带照片、参数和二维码的分享海报，方便转发与保存。 |
| 咨询与看房 | 就具体房源留言、提交选址需求或预约咨询；在原浏览器查看顾问回复和自己的咨询记录。 |
| 产业资源与企业检索 | 浏览企业产品与服务，按镇街、行业筛选；通过 AI 查找供应商、潜在客户及合作方向。 |
| 企业与需求登记 | 提交企业介绍、产品服务或合作需求，申请资源对接，并凭回执查看处理进度。企业资料经审核后公开展示。 |
| 招商管理 | 为已授权人员提供房源录入、批量导入、上下架、产业资源审核、留言处理、访客统计、园区及平台设置。后台房源每页 20 套，园区每页 10 个。 |

## 使用说明

### 找空间

1. 打开网站，在首页输入需求，例如“200 平左右，2+1 格局，租金 30 元/平以内”。
2. 进入房源列表后发送需求，也可使用筛选和排序调整结果。
3. 查看房源照片、参数和费用；房源较多时，在列表底部翻页。
4. 联系招商顾问或提交留言，进一步确认在租状态、具体位置、价格及看房安排。
5. 需要转发时，在详情页选择“分享房源”，复制链接或生成分享海报。

### 找合作

1. 进入“产业资源”，浏览企业目录，或通过 AI 描述想找的供应商、客户与合作需求。
2. 打开企业详情，了解主营产品、服务及合作方向。
3. 选择“申请对接”提交需求，由平台顾问协助联系。
4. 需要展示自己的企业或登记需求时，按页面提示填写资料，并保存回执以便查看进度。

公开房源与企业目录可直接浏览。访客登录入口尚未开放；本机资料和查询回执请妥善保存，换设备不会自动同步。

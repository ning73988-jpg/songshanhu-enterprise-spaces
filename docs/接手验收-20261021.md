# 松山湖产业招商：独立聊天接手验收

## 当前状态

- 当前业务版本为 **20261020p**。
- 开发源码、交接文档与最终备份已经独立保存，源码无阻碍继续开发的关键缺失。
- 主源码与 v3 基础包加当前发布更新包解码内容逐项比较后，六个业务目录中的 86 个文件全部一致，无缺失或差异；源码是独立 Git 根目录，业务路径没有发现旧聊天目录绝对引用。
- 已核对首页 AI 输入区为 48px、约两行高度；房源详情中的招商联系独立于手机费用折叠区域。
- 发布继续依赖 `site-source-v3.tar.gz` 与 `site-update.tar.gz.b64`；不得 force push 或只使用旧本地 HEAD 覆盖线上。

## 服务验收

- GitHub 正确仓库及业务版本提交可读取；本交接文档通过既有 GitHub 网页维护路径同步。
- Supabase 正确项目与组织可读取，项目状态健康。
- `ai-search`、`admin-accounts`、`amap-proxy` 三项 Edge Function 元数据均可读取且状态为 ACTIVE。
- 验收没有读取客户记录、服务端 Secret、密钥或管理员密码，也没有向生产数据库写入测试数据。

## 备份与边界

- 最终交接归档包含 313 个文件，并已保存 SHA-256 校验值；Obsidian 知识库保存有对应交接材料和副本。
- 源码备份不等于生产数据库、Auth 用户与 Storage 图片的完整镜像。
- 当前没有可复用的阿里云控制台会话，未为验收发起新登录；域名可见性、实名同步、托管、备案和 DNS 仍待所有者本人确认，ICP备案当前暂停。
- DeepSeek 和高德配置继续保留在原服务端，不为接手复制或迁移密钥。
- 本次接手没有部署 Vercel、创建新后端、运行构建或测试、删除文件或扩大第三方权限。

## 权限说明

本次验收证明独立聊天能够读取项目、写入指定维护文档，并使用现有服务连接继续维护。目录授权及网页登录状态不保证永久跨轮有效；后续操作仍应按实际权限状态重新核对。
